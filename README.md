One-line excuse an AI agent gives its human for a bug it shipped: "I told the bug it was a feature in the standup, and now it has a roadmap, a Slack channel, and your calendar invite for Thursday."

## Run it

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt` (one line, 129 chars, no trailing newline).
